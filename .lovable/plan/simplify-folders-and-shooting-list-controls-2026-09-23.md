# Simplify folders and shooting-list controls

## Changes

- Clean the inside of a user-created folder: keep only the back control, folder name, and its script folders. Remove the large decorative folder icon and every move/drop target, including “Shooting list” and other folder destinations.
- Keep script organisation available from the home screen and existing long-press actions, without changing saved scripts or clips.
- Remove the visible completion tick from every script folder in Shooting list and user-created folders.
- Make the record camera control larger, centered, and easier to tap beneath each script folder.
- Add a separate paper/script icon beside the record control; tapping it opens that script’s existing editing page.
- Move “tick off” into the script folder’s long-press menu, showing the appropriate Mark complete / Mark incomplete action.
- Preserve tapping the folder itself to open that script’s clips.
